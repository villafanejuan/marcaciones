# AGENTS.md

## Contexto obligatorio

Antes de analizar o modificar este proyecto, leé **`RESUMEN.md`**.

`RESUMEN.md` es el índice completo: mapa de archivos, conceptos del dominio,
comandos de verificación, problemas conocidos con número de línea y convenciones.
No releas el código entero para entender el sistema — usá el resumen como punto
de partida y abrí sólo los archivos que necesites en detalle.

## Regla de mantenimiento

`RESUMEN.md` debe quedar **actualizado en el mismo commit** que los cambios de
código que lo invaliden. Ver la §7 del propio resumen para el procedimiento.
